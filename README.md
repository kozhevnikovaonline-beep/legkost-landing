# Онлайн-школа «ЛЁГКОСТЬ»: лендинг + Telegram Mini App

```
Проект фитнес тренер/
├── README.md                          ← этот файл
├── docs/
│   ├── 01-концепция-и-структура.md    ← концепция, палитры, ЦА, офферы
│   ├── 02-чек-лист-замен-и-запуск.md  ← что заменить, Telegram, Метрика, 5 идей
│   ├── 03-сценарий-бота.md            ← воронка в Telegram-боте
│   ├── 04-seo-аудит.md                ← SEO-проверка по 21 пункту
│   └── 05-mini-app.md                 ← Mini App: функции, бот, запуск, деплой
├── miniapp/                           ← Telegram Mini App (Vite + React + TS) и сервер
└── site/
    ├── index.html                     ← сайт (HTML+CSS+JS одним файлом)
    ├── privacy.html                   ← политика ПДн (шаблон)
    └── assets/img, assets/icons       ← сюда класть свои фото и favicon
```

Открыть сайт: двойной клик по `site/index.html`.
Все места для замены помечены в коде комментарием `ЗАМЕНИТЬ`.

Mini App: https://kozhevnikovaonline-beep.github.io/legkost-landing/app/ — инструкция в `docs/05-mini-app.md`.
