# Чек-лист: что заменить перед запуском

Сайт: `site/index.html` (+ `site/privacy.html`). Все места для замены помечены в коде комментарием `ЗАМЕНИТЬ`.

## Принятые решения (этап 1)
- Название: **«ЛЁГКОСТЬ» — система Алёны Ветровой** (автор вымышленный)
- Заголовок: вариант 3 — «Почему вес стоит, даже если вы едите мало?»
- Палитра A «Неоновая сила»: `#0E0B0F` / `#FF2E8A` / `#FFF1F6` / лайм `#C6FF4A`
- Кодовое слово: **ЛЁГКОСТЬ**
- Слайдер до/после **не сделан**: на стоковых сайтах нет честных пар «до/после» одного человека. Вместо него — отзывы с круглыми фото. Когда появятся реальные фото учениц (с согласия), слайдер можно добавить.

## 2. Заявки в Telegram
В `index.html`, в самом начале `<script>`, есть объект `CONFIG`:
```js
TG_BOT_TOKEN: 'PASTE_BOT_TOKEN_HERE',
TG_CHAT_ID:   'PASTE_CHAT_ID_HERE',
WEBHOOK_URL:  '',
YM_ID: 0
```
1. В Telegram откройте @BotFather → `/newbot` → получите **токен**.
2. Напишите своему боту любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":…}`. Это **chat_id**. Для группы: добавьте бота в группу, chat_id будет начинаться с `-100`.
3. Вставьте оба значения в `CONFIG`.

⚠ **Важно:** токен в коде сайта видит любой посетитель. Его могут использовать для спама в ваш чат. Надёжнее отправлять заявки через посредника и прописать его адрес в `WEBHOOK_URL`: Cloudflare Worker, n8n, Make, Albato или PHP-скрипт на хостинге. Тогда токен останется на сервере.

Пока токен не задан, форма работает в демо-режиме: показывает «Спасибо», а заявку пишет в консоль браузера.

## 3. Яндекс Метрика
1. Создайте счётчик → в `<head>` раскомментируйте блок «Яндекс Метрика» и замените `00000000` на номер.
2. Тот же номер укажите в `CONFIG.YM_ID`.
3. В Метрике создайте цели типа **«JavaScript-событие»** с такими идентификаторами:

| Цель | Когда срабатывает |
|---|---|
| `form_submit` | **заявка отправлена (главная)** |
| `cta_hero`, `cta_header`, `cta_menu`, `cta_quiz`, `cta_calc`, `cta_final`, `cta_sticky` | клики по кнопкам CTA |
| `messenger_tg`, `messenger_vk`, `phone_click` | клики по мессенджерам и телефону |
| `thanks_bot` | переход в бота после заявки |
| `quiz_done` | отмечено 2+ пункта в тесте |
| `calc_done` | двигали калькулятор |

## 5. Пять идей для роста конверсии
1. **Видео-кружок автора на первом экране** (15 сек, «Привет, я Алёна…»). Живое лицо даёт +20–40% доверия, особенно для аудитории 35+.
2. **Квиз вместо формы.** 4 вопроса (возраст, сколько хотите сбросить, что мешает, мессенджер), в конце — «ваш персональный план». Заявок обычно в 1,5–2 раза больше, чем через обычную форму.
3. **Реальные отзывы-скриншоты и видео-отзывы** вместо текстовых карточек, плюс слайдер «до/после» с настоящими фото.
4. **Честный дедлайн потока**: дата старта и «запись закрывается за 3 дня до старта». Без фейковых таймеров, только реальные даты.
5. **Ретаргетинг и цепочка в боте**: тем, кто забрал гайд, но не купил, бот через 1, 3 и 7 дней присылает кейс → бесплатный эфир-разбор → спецпредложение на 48 часов. Сценарий — в `03-сценарий-бота.md`.

## 7. Изменения после тестов
- Лид-магнит теперь **3 бесплатных видеоурока** вместо PDF-гайда: «Почему вес стоит», «Тарелка без голода + меню на 3 дня», «Плоский живот: тренировка дома». Уроки нужно записать и загрузить в бота.
- С сайта убраны: часы работы, ИНН/ОГРНИП, гарантия возврата. Телефон — заглушка `+7 (000) 000-00-00`.
- Мобильная версия проверена на ширинах 320, 360, 375, 393, 412, 430 (iPhone SE…Pro Max, Android), 768 и 1024 px: горизонтальной прокрутки нет, учтены вырезы экрана iPhone (safe-area), поля не увеличивают страницу на iOS, нет «залипания» hover на сенсорных экранах.
- WhatsApp убран со всего сайта (кнопки, подвал, выбор мессенджера в форме).
- Типографика: неразрывные пробелы после предлогов и союзов, «балансировка» строк в заголовках, заголовок главного экрана на десктопе — ровно в 3 строки. Переносы проверены на 320–1920 px.
- Длительность программы изменена на **31 день** (было 28): все тексты, мета-теги, Schema, этапы программы «Дни 1–7 / 8–14 / 15–21 / 22–31».
