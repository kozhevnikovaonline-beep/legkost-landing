## 1. Что умеет приложение

| Раздел | Что внутри |
|---|---|
| **Онбординг** (3 экрана) | Знакомство с Алёной → подарок «3 урока» → лепестки. Кнопка «Открыть 3 урока бесплатно» выдаёт лид-магнит, +500 лепестков и просит разрешить боту писать (для напоминаний об уроках). |
| **Главная** | Приветствие по имени из Telegram, следующий урок с прогрессом, ежедневный подарок (серия 7 дней: 100 → 2 500 лепестков), квиз «Ваш тип набора веса», метод «3 опоры», статистика, отзывы, карточка автора. |
| **Уроки** (лид-магнит) | 3 урока с сайта: «Почему вес стоит: 7 скрытых причин», «Тарелка без голода + меню на 3 дня», «Плоский живот: тренировка дома». Уроки открываются по порядку. Внутри видео (когда вставите ссылку), конспект, чек-листы с сохранением, домашнее задание и материалы. После 3-го урока открывается **бонус-эфир «Питание при гормональных сбоях»**. |
| **Лепестки** (тапалка в центре) | Большая монета-лепесток: «+1» при тапе, вибрация, мультитач, энергия с восстановлением. Уровни от «Первый шаг» до «Амбассадор». **Бусты**: сильный тап, запас сил, быстрое восстановление. **Задания**: уроки, квизы, канал, напоминания, первый гайд. **Пригласи подругу**: +2 000 лепестков. |
| **Магазин** | Продукты из «Воронка ЛЁГКОСТЬ — вариант 2». **Гайды** — за лепестки целиком или за рубли. **Программы и курсы** — за рубли, а лепестки дают скидку до 30% (1 лепесток = 1 ₽). Персональная рекомендация по квизу «Какой формат мне подходит». |
| **Профиль** | Аватар и имя из Telegram, уровень, статистика, тип и формат из квизов, «Мои материалы», об авторе, куратор, канал, сайт, вибрация, политика. |

## 2. Архитектура

```
miniapp/
├── index.html               ← подключает telegram-web-app.js
├── shared/                  ← общая логика клиента и сервера
│   ├── economy.ts           ← энергия, тапы, бусты, награды, уровни, скидки
│   ├── actions.ts           ← все действия пользователя (один редьюсер)
│   ├── catalog.ts           ← цены продуктов и состав пакетов
│   └── validate.ts          ← безопасный разбор сохранённых данных
├── src/
│   ├── telegram/            ← обёртка WebApp API: fullscreen, тема, safe area,
│   │                          BackButton (стек), MainButton, haptics, CloudStorage
│   ├── api/                 ← mockApi (без сервера) и httpApi (с сервером)
│   ├── store/               ← состояние: оптимистичные действия + откат при ошибке
│   ├── content/             ← ВСЕ ТЕКСТЫ: уроки, гайды, продукты, квизы, отзывы
│   ├── components/, screens/, styles/global.css
├── server/                  ← бэкенд Node + TypeScript без зависимостей
│   └── src/ index.ts (API), telegramAuth.ts (проверка initData), bot.ts, db.ts
└── tests/                   ← тесты экономики и проверки подписи (15 шт.)
```

**Как работает без сервера (сейчас).** Прогресс хранится в Telegram CloudStorage (синхронизация между телефоном и компьютером) и в localStorage. Оплата демонстрационная: продукт отмечается купленным после подтверждения.

**Как работает с сервером.** Задаёте `VITE_API_URL`, и каждое действие уходит на сервер с подписанным `initData`. Сервер проверяет HMAC-подпись Telegram, пересчитывает экономику той же логикой (`shared/`), режет автокликер (не больше 20 тапов/сек и не больше энергии), выдаёт счета через Telegram Payments (ЮKassa) и начисляет реферальные бонусы.

**Telegram-интеграция.**
- `ready()`, `expand()`, `requestFullscreen()` на iOS/Android (Bot API 8.0+), `disableVerticalSwipes()`, чтобы свайп не закрывал приложение во время тапов.
- Шапка и фон окрашиваются в цвет бренда. Тёмная или светлая тема берётся из Telegram.
- Отступы учитывают safe area и кнопки Telegram в fullscreen (`--tg-content-safe-area-inset-*`).
- Нативные MainButton и BackButton. В браузере вместо них рисуются свои.
- Вибрация на тапах и действиях, `requestWriteAccess`, `openInvoice`, `openTelegramLink`.
- Deep links: `?startapp=lesson-2`, `guide-cortisol`, `system`, `shop`, `tap`, `quiz-format`, `ref_<id>`.

## 3. Запуск локально

Нужен Node.js 22.18+ (проверено на 24).

```bash
cd miniapp
npm install
npm run dev        # http://localhost:5173 — демо-режим в браузере
npm test           # тесты
npm run build      # сборка в miniapp/dist
```

Сервер (по желанию):
```bash
cd miniapp
cp server/.env.example server/.env   # заполнить BOT_TOKEN и WEBAPP_URL
npm run server                        # API на :8080 + бот (long polling)
```

## 4. Настройка Telegram-бота (10 минут)

1. Откройте **@BotFather** → `/newbot` → имя «ЛЁГКОСТЬ · Алёна Ветрова», юзернейм, например `legkost_guide_bot`. Сохраните **токен**.
2. `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App** → URL:
   `https://kozhevnikovaonline-beep.github.io/legkost-landing/app/`
3. Если в настройках Mini App есть режим запуска, выберите **Fullscreen**. В любом случае приложение само переходит в полноэкранный режим на iOS и Android, а ссылки с `&mode=fullscreen` открывают его на весь экран сразу.
4. `/newapp` → выберите бота → название «ЛЁГКОСТЬ», описание, картинка 640×360, тот же URL, короткое имя `app`.
   Ссылка на приложение: `https://t.me/legkost_guide_bot/app?mode=fullscreen`
5. **Menu Button**: `/mybots` → Bot Settings → Menu Button → URL приложения, текст «Уроки». Если запущен сервер, он настроит кнопку сам.
6. Описание и аватар: `/setdescription`, `/setabouttext`, `/setuserpic`.
7. **Оплата** (когда будете готовы): BotFather → Payments → ЮKassa → получить `PAYMENT_PROVIDER_TOKEN` → вписать в `server/.env`.

**Связка с сайтом:** кнопки сайта уже ведут на `t.me/legkost_guide_bot?start=...`. Если у бота будет другой юзернейм, замените его на сайте и в `VITE_BOT_USERNAME`.

### Без своего сервера (через SaleBot / BotHelp)
Приложение работает и в демо-режиме: прогресс хранится в Telegram CloudStorage. В конструкторе бота на /start отправьте сообщение с кнопкой типа **Web App** на URL приложения. Тексты приветствия — в `server/src/bot.ts` (константа `WELCOME`) и в `docs/03-сценарий-бота.md`.

## 5. Деплой

**Фронтенд (уже настроено).** При каждом push в `main` GitHub Actions (`.github/workflows/pages.yml`) проверяет типы и тесты, собирает Mini App и публикует её вместе с сайтом:
- сайт → `/legkost-landing/`
- приложение → `/legkost-landing/app/`

Настройки сборки (необязательно): GitHub → Settings → Secrets and variables → Actions → **Variables**: `VITE_API_URL`, `VITE_BOT_USERNAME`, `VITE_APP_SHORTNAME`, `VITE_CHANNEL_URL`, `VITE_CURATOR_URL`.

**Сервер (для боевого запуска).** Любой VPS или PaaS с Node 22.18+ (Timeweb Cloud, Selectel, Render, Railway, Fly.io):
```bash
git clone <репозиторий> && cd legkost-landing/miniapp
npm ci --omit=dev
cp server/.env.example server/.env && nano server/.env
node server/src/index.ts       # лучше через pm2 / systemd
```
Нужен HTTPS-домен для API, например `https://api.legkost-online.ru`. Его адрес укажите в переменной `VITE_API_URL` и перезапустите workflow. Данные лежат в `server/data/users.json`: делайте резервные копии, а при росте аудитории замените на PostgreSQL (интерфейс `Db` в `db.ts`).

## 7. Проверенные сценарии

- Онбординг → выдача лид-магнита (+500 лепестков) → открытие урока 1.
- Чек-лист урока сохраняет отметки и показывает вывод по числу совпадений.
- «Урок пройден» → +300 лепестков → автоматически открывается урок 2. Урок 3 закрыт, пока не пройден урок 2.
- Тапалка: лепестки, «+1», энергия убывает и восстанавливается, бусты, восстановление энергии 3 раза в день.
- Задания: список, статусы «Готово / Забрать / Перейти», приглашение подруги.
- Квиз «Какой формат мне подходит» → результат → рекомендация в магазине.
- Покупка гайда за лепестки → гайд открывается.
- Скидка лепестками (до 30%) → итоговая цена пересчитывается → демо-оплата «СИСТЕМЫ» открывает программу и 3 гайда.
- Главная и профиль, тёмная и светлая темы, мобильный экран 375×812, ошибок в консоли нет.
- Сервер: без подписи → 401; подделка задания → 409; автокликер ограничен; демо-оплата открывает пакет.
- Автотесты: 15/15.

**Не проверено (нужен ваш бот):** запуск внутри Telegram на iOS/Android (fullscreen, нативные кнопки, вибрация, CloudStorage) и настоящая оплата через ЮKassa.
